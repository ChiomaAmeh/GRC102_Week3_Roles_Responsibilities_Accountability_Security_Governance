# Roles, Responsibilities and Accountability in Security Governance
 
## GRC102 Week 3 Practical Lab
 
### Repository Purpose
 
This repository contains the complete Week 3 Security Governance practical laboratory for TechGlobal.
 
The project transforms an informal IT-centric security governance model into a structured governance framework that introduces:
 
- Board oversight
- Executive accountability
- Security governance committees
- RACI accountability model
- Cyber-risk escalation workflow
- Segregation of duties controls
 
## Repository Structure
