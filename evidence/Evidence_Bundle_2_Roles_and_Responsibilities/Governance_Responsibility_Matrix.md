# Cross-Functional Governance Responsibility Matrix
 
## Overview
 
This matrix defines the primary governance responsibilities of key stakeholders within TechGlobal's security governance operating model.
 
| Stakeholder | Key Governance Responsibilities |
|------------|--------------------------------|
| Board of Directors | Approves risk appetite, monitors cyber-risk exposure, provides strategic oversight |
| CEO | Provides executive sponsorship and ensures cybersecurity aligns with business objectives |
| CISO | Develops security strategy, manages governance programme, reports cyber risk |
| CRO / Risk Officer | Integrates cyber risk into enterprise risk management |
| Legal Counsel | Advises on compliance, privacy, regulatory, and contractual obligations |
| Finance Director | Approves security budgets and evaluates financial risks |
| HR Director | Manages workforce governance, awareness, onboarding, and disciplinary actions |
| IT Director | Implements approved technical controls and security solutions |
 
---
 
## Decision Authority Summary
| Governance Area | Primary Decision Authority |
|----------------|---------------------------|
| Risk Appetite | Board of Directors |
| Security Strategy | CEO and Board |
| Security Policies | CISO |
| Security Budget Approval | Finance Director and CEO |
| Cyber-Risk Reporting | CISO |
| Enterprise Risk Management | CRO |
| Regulatory Compliance | Legal Counsel |
| Workforce Security Controls | HR Director |
| Technical Security Implementation | IT Director |
 
---
 
## Accountability Principles
- Board retains ultimate oversight responsibility.
- CEO owns executive accountability.
- CISO owns cybersecurity governance.
- Business leaders retain accountability for risks within their operations.
- IT implements controls but does not independently govern security risk.
- Risk acceptance requires executive authorization.
