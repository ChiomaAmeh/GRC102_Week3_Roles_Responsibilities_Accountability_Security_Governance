# 12-Month Governance Calendar
| Month | Governance Activity |
|---------|---------------------|
| January | Security Strategy Review |
| February | Enterprise Risk Assessment |
| March | Board Cyber-Risk Briefing |
| April | Security Policy Review |
| May | Security Awareness Campaign |
| June | Compliance Assessment |
| July | Mid-Year Risk Review |
| August | Security Budget Planning |
| September | Board Governance Update |
| October | Internal Audit Review |
| November | Governance Maturity Assessment |
| December | Annual Governance Review |
 
---
 
# Annual Governance Objectives
The governance calendar ensures:
- Continuous oversight.
- Scheduled risk reviews.
- Regular Board reporting.
- Policy maintenance.
- Continuous improvement.

 
The calendar supports TechGlobal's governance throughout the year.
