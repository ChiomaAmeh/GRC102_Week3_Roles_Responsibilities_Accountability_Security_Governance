# RACI Accountability Matrix
## Purpose
This RACI Accountability Matrix defines ownership, accountability, consultation requirements, and reporting relationships for key security governance activities across TechGlobal.

 
The matrix ensures that governance activities have clear responsibility assignments and prevents ambiguity, duplication of effort, and accountability gaps.

---
 
## RACI Definitions
| Code | Meaning | Description |
|--------|----------|-------------|
| R | Responsible | Performs the work |
| A | Accountable | Ultimately answerable for outcomes |
| C | Consulted | Provides input before decisions |
| I | Informed | Receives updates after decisions |

## RACI Matrix Analysis
### Key Observations
1. Accountability is assigned to a single role for each activity.
   
3. Security governance ownership is shared across business functions and is not concentrated within IT.
 
4. Executive management maintains accountability for governance implementation.
 
5. Board oversight remains focused on strategic governance and risk management.
 
6. Legal, Finance, and HR actively participate in governance activities.
